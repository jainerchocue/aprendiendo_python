- **`temas/`** — Archivos `.py` con explicaciones, ejemplos activos y ejercicios comentados paso a paso.
- **`ejercicios/`** — Guías `.md` con enunciados y objetivos para practicar por tu cuenta.

## Cómo usar este repositorio

1. **Elige un tema** de la [Ruta de Aprendizaje](#ruta-de-aprendizaje).
2. **Lee primero los enunciados** en su guía dentro de `ejercicios/`.
3. **Intenta resolverlos por tu cuenta** antes de mirar la solución.
4. **Compara y experimenta** con los ejemplos de `temas/` (los bloques entre `"""..."""` están comentados para que puedas ir descomentando y probando uno a uno).

<details>
<summary>Cómo descargar y ejecutar los archivos en tu computadora</summary>

1. Clona el repositorio o descárgalo en ZIP desde el botón **`Code`**:
   ```bash
   git clone https://github.com/jainerchocue/aprendiendo_python.git
   cd aprendiendo_python
   ```
2. Ejecuta cualquier tema con Python 3:
   ```bash
   python temas/Variables.py
   ```
3. Si algún ejemplo está entre `""" ... """`, quita las comillas triples de ese bloque para ejecutarlo y ver su resultado.

</details>
