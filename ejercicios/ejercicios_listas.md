## Ejercicio 1 — Crear una lista simple

**Enunciado:**
Crea una lista llamada `frutas` que contenga tres frutas de tu elección y muéstrala completa.

**Objetivo:**
- Entender cómo se crea una lista en Python
- Aprender la sintaxis básica de listas

---

## Ejercicio 2 — Acceder a elementos por índice

**Enunciado:**
Crea una lista llamada `colores` con tres colores y muestra cada elemento individualmente usando su índice.

**Objetivo:**
- Entender cómo funcionan los índices en las listas
- Aprender que las listas empiezan en índice 0

---

## Ejercicio 3 — Agregar elementos a una lista

**Enunciado:**
Crea una lista llamada `numeros` con los números 1, 2, 3 y luego agrega el número 4 al final de la lista usando el método `append()`.

**Objetivo:**
- Aprender a agregar elementos a una lista existente
- Entender cómo funciona el método `append()`

---

## Ejercicio 4 — Recorrer una lista con un ciclo

**Enunciado:**
Crea una lista llamada `nombres` con tres nombres y usa un ciclo `for` para mostrar cada nombre individualmente.

**Objetivo:**
- Entender cómo recorrer una lista con un ciclo
- Aprender la sintaxis del ciclo `for` con listas

---

## Ejercicio 5 — Obtener la longitud de una lista

**Enunciado:**
Crea una lista llamada `letras` con cinco letras y usa la función `len()` para mostrar cuántos elementos tiene la lista.

**Objetivo:**
- Aprender a obtener la cantidad de elementos de una lista
- Entender cómo funciona la función `len()`

---

## 💡 Tips para resolver:

- Las listas se crean usando corchetes `[]`
- Los elementos se separan por comas
- Los índices empiezan en 0 (primer elemento), 1 (segundo), etc.
- `append()` agrega elementos al final de la lista
- `len()` devuelve la cantidad de elementos
