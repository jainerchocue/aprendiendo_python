## Ejercicio 1 — Evaluar edad

**Enunciado:**
Crea un programa que pida al usuario ingresar su edad y muestre:
- "Eres menor de edad" si la edad es menor de 18
- "Eres adulto" si la edad está entre 18 y 64
- "Eres adulto mayor" si la edad es mayor de 64

**Objetivo:**
- Entender cómo funcionan `if`, `elif` y `else`
- Aprender a evaluar rangos de valores

---

## Ejercicio 2 — Verificar si un número es par o impar

**Enunciado:**
Crea un programa que pida al usuario ingresar un número entero y muestre:
- "El número es par" si es divisible por 2
- "El número es impar" si no es divisible por 2

**Objetivo:**
- Aprender a usar el operador módulo `%`
- Entender cómo detectar números pares e impares

---

## Ejercicio 3 — Verificar si un número es positivo, negativo o cero

**Enunciado:**
Crea un programa que pida al usuario ingresar un número y muestre:
- "El número es positivo" si es mayor que 0
- "El número es negativo" si es menor que 0
- "El número es cero" si es igual a 0

**Objetivo:**
- Practicar comparaciones numéricas
- Entender los diferentes operadores de comparación

---

## Ejercicio 4 — Encontrar el mayor de dos números

**Enunciado:**
Crea un programa que pida al usuario ingresar dos números y muestre:
- "El primer número es mayor" si el primero es mayor
- "El segundo número es mayor" si el segundo es mayor
- "Ambos números son iguales" si son iguales

**Objetivo:**
- Aprender a comparar múltiples valores
- Entender cómo manejar igualdades

---

## Ejercicio 5 — Sistema de login básico

**Enunciado:**
Crea un programa que simule un sistema de login:
- Define un usuario correcto y una contraseña correcta
- Pide al usuario ingresar su nombre y contraseña
- Muestra "¡Login exitoso!" si ambos coinciden
- Muestra "Contraseña incorrecta" si el usuario es correcto pero la contraseña no
- Muestra "Usuario no encontrado" si el usuario no coincide

**Objetivo:**
- Aplicar condicionales a un caso práctico
- Entender cómo funcionan los sistemas de autenticación básicos

---

## 💡 Tips para resolver:

- Usa `if` para la primera condición
- Usa `elif` para condiciones alternativas
- Usa `else` para cuando ninguna condición anterior se cumple
- El operador `%` devuelve el residuo de una división
- Los operadores de comparación son: `>`, `<`, `>=`, `<=`, `==`, `!=`
